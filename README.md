# Контроль договоров и разбор документов

Программа для Windows для юридического отдела. Открывается в браузере на вашем компьютере,
работает без интернета, документы и персональные данные никуда не отправляются.

Что умеет (пробная версия):

- загружает портфель из выгрузки CRM (Excel или CSV; проверено на 700 000 строк);
- принимает пачки документов (10 или 1000 файлов, можно папкой), читает их (текст и сканы),
  находит договор в портфеле (по номеру договора, ИНН, номеру дела, ФИО и дате рождения);
- показывает, что привязано, что нужно подтвердить, что не найдено, что уже разобрано;
- записывает найденное в карточку договора и считает сроки (исковая давность, повторное
  предъявление листа, реестр кредиторов, наследство, плановые проверки ИП, ИП без движения);
- показывает свежесть разбора: если документы по договору разбирали недавно, повторно загружать не нужно;
- заполняет шаблоны документов (Word), недостающие данные подсвечивает.

Не входит в эту версию: мониторинг открытых источников (нужен интернет), общая база для
нескольких компьютеров, права доступа. Правила расчёта сроков условные и требуют согласования юристами
(параметры меняются в разделе «Настройки»).

## Запуск

Распакуйте архив в папку с коротким путём, например `C:\Razbor`, и запустите `RazborDocs.exe`.
Откроется страница в браузере. Данные хранятся в папке `Данные` рядом с программой
(база, загруженные документы, созданные Word-файлы). Папку `Данные` не отправляйте и не
загружайте в репозиторий: в ней персональные данные.

Порядок работы: 1) «Сводка» → загрузить портфель из CRM; 2) «Загрузка документов» → перетащить
файлы; 3) проверить привязку и нажать «Записать в карточки»; 4) смотреть «Сроки» и «Исполнительные
производства»; 5) в карточке договора выбрать шаблон документа.

Для разработчика: `python app.py` запускает программу, `python tests/test_app.py` проверяет ядро,
`python tools/make_demo_crm.py demo.csv` создаёт вымышленную выгрузку CRM (с `--rows 700000` для
проверки скорости).

# Простой режим: разбор папки в Excel

`RazborDocs.exe --gui` открывает прежнее простое окно, `--cli` работает из командной строки.

## Как пользоваться

1. Распакуйте архив в папку с коротким латинским путём, например `C:\Razbor`.
2. Запустите `RazborDocs.exe`.
3. Выберите папку с документами, при желании измените, куда сохранить Excel.
4. Нажмите «Начать обработку». Остановить можно в любой момент: уже обработанное попадёт в таблицу.
5. Откройте результат. Имя файла в таблице — ссылка на оригинал.

Если запустить повторно на той же папке, уже распознанные файлы берутся из кэша
(`...кэш.sqlite` рядом с Excel), поэтому повтор идёт за секунды. Кэш и Excel содержат
персональные данные: храните их там же, где сами документы.

## Листы Excel

- **Итоги**: сколько файлов, сколько нужно проверить, разбивка по видам и суммам.
- **Документы**: строка на файл со всеми найденными полями.
- **Проверить**: файлы, в которых программа не уверена, и причина.
- **Дубли**: точные копии, одинаковый текст в разных файлах, вероятные дубли (тот же вид, дело и дата).
- **Ошибки**: файлы, которые не удалось прочитать (пароль, повреждён).
- **Поля (детально)**: у каждого значения страница и фрагмент текста, чтобы сверить за секунды.

## Важно о точности

Поля находятся по типовым формулировкам. На чистых текстовых документах точность высокая,
на плохих сканах ниже. Сумма и даты, выбранные «по максимуму» или с низкой уверенностью
распознавания, попадают в лист «Проверить». Перед принятием решений по должнику сверяйте
значения с оригиналом. ФИО возвращается в той форме, как в документе (например, в родительном падеже).

## Свои поля без пересборки

Положите рядом с программой файл `polya.json` (пример: `polya.example.json`): для каждого
поля имя, регулярное выражение и номер группы. Новые столбцы появятся в Excel.

## Дополнительная защита

Чтобы быть уверенным, что программа не выходит в сеть, добавьте правило брандмауэра
(PowerShell от администратора):

    New-NetFirewallRule -DisplayName "RazborDocs без сети" -Direction Outbound -Action Block -Program "C:\Razbor\RazborDocs.exe"
    New-NetFirewallRule -DisplayName "Tesseract без сети" -Direction Outbound -Action Block -Program "C:\Razbor\tesseract\tesseract.exe"

## Сборка .exe

Собирается на Windows. Два способа:

1. **GitHub Actions** (ничего ставить не нужно). Создайте **приватный** репозиторий, загрузите в него
   содержимое этой папки (документы с реальными данными в репозиторий не кладите), откройте
   вкладку Actions → «Сборка для Windows» → Run workflow. Через несколько минут появится
   артефакт `RazborDocs.zip`. Перед сборкой workflow сам прогоняет тесты на выдуманных документах.
2. **Локально**: установите Python 3.12 и Tesseract (сборка UB Mannheim), затем
   `pip install -r requirements.txt -r requirements-build.txt` и `python tools\build_windows.py`.

## Для разработки

    python tools/make_samples.py ПАПКА        # выдуманные тестовые документы
    python tests/test_samples.py ПАПКА        # сквозная проверка
    python tools/dump_text.py файл.pdf        # какой текст видит программа
    python app.py --cli ПАПКА результат.xlsx  # запуск без окна

Для запуска из исходников нужны Python 3.10+, `pip install -r requirements.txt`, Tesseract
с `rus.traineddata` (пути можно задать переменными `RAZBOR_TESSERACT` и `RAZBOR_TESSDATA`).
Для более точного, но более медленного распознавания замените файлы в папке `tessdata` на
модели `tessdata_best`.




## Судебные досье и калькулятор (ветка разработки)

ИИ временно отключён. Для работы не требуется Ollama, внешние модели или подключение к интернету.

1. Откройте «Загрузка документов», загрузите судебные акты одного должника (или несколько групп).
2. После чтения нажмите «Собрать судебное досье», отметьте нужные документы и задайте название.
   Портфель CRM для этого не требуется. Можно добавлять новые документы в ранее созданное досье.
3. В разделе «Судебные досье» просмотрите хронологию, номера дел, суды, найденные признаки
   отмены, изменения, взыскания и продолжающегося начисления с фрагментами исходного текста.
4. После проверки оригиналов вручную укажите выбранный судебный акт и основание заключения.
   При добавлении новых документов выбор сбрасывается: юридическая сила не определяется автоматически.
5. Откройте калькулятор из досье. Введите подтверждённую базу начисления, даты, годовую ставку
   либо историю ставок, частичные погашения базы. Нажмите «Рассчитать и сохранить».
   История расчётов хранится в локальном досье; она не заменяет остаток в CRM.

Загруженные документы читаются по всем страницам; для подключённых папок остаётся прежний
лимит OCR с предупреждением. Сохраняются извлечённые сведения. При создании досье можно отдельно выбрать сохранение локальной копии оригиналов.
Даты и реквизиты распознаются эвристически и могут быть ошибочными; сверяйте оригиналы.
Нельзя автоматически складывать суммы судебных актов или определять юридическую силу по дате.
Калькулятор поддерживает простые годовые и дневные ставки, выбор годового делителя
(фактические 365/366, фиксированные 365, 366 или 360), включительные границы периода
и выбор момента уменьшения базы (в день платежа либо со следующего дня). Параметры подтверждаются
по акту; программа не назначает их автоматически. Не учитывает особые ограничения,
капитализацию, моратории, индексацию и автоматическое распределение платежей.
В блоке «Несколько начислений одновременно» можно рассчитать до 20 отдельных оснований
с разными базами, ставками, периодами и погашениями. Суммируются только начисления после
ручного подтверждения; базы не суммируются. При изменении платежей/выбранного акта история
остаётся доступной, но помечается для повторной сверки.

### Контроль неоднозначных судебных актов

- Мотивировка, требования, историческая задолженность, базы будущих начислений,
  фиксированные взыскания и общий итог суда показываются раздельно.
- Отказные пункты не включаются в итог; при неоднозначной расшифровке, суммах «в том числе»,
  неполном документе, нескольких резолютивных частях, долях, солидарности, зачёте,
  изменении или особом порядке исполнения единый итог блокируется.
- Сравниваются явный итог мотивировки с распознанными долговыми позициями и
  формулировки об истце/получателе взыскания и названном получателе уступленного права.
  Проверяются также итоги задолженности за совпадающий период. Различия — повод для проверки, не исправление документа.
- Просьба о правопреемстве, отказ или отсутствие однозначного предписания о замене стороны
  не заменяют кредитора автоматически. При подозрительных реквизитах требуется ручная привязка.
- Признаки эвристические, не исчерпывающие: нестандартная формулировка, ошибки OCR,
  иностранная валюта, несколько договоров, разделение сумм по получателям, смешанные судебные
  акты, специальные правовые ограничения требуют проверки человеком. Отсутствие предупреждения
  не гарантирует отсутствие особенностей. Все найденные сведения сверяйте по оригиналу.
История переменных ставок вводится пользователем, без автоматической загрузки.
Новые тесты: python tests/test_dossiers.py и python tests/test_interest_ai.py InterestTest.


## Расширенные автономные инструменты

- В досье можно импортировать XLSX (активный лист) или CSV UTF-8/Windows-1251 с разделителем `;`.
  Заголовки: Дата;Сумма;В базу;Номер платежа. Даты ISO или ДД.ММ.ГГГГ.
  Номер платежа обязателен; неизвестную сумму в базу оставляйте пустой.
  Для сохранения ведущих нулей задавайте номера платежей текстом. Импортируйте только платежи нужного должника.
- Справочник ставок заполняется проверенной полной историей в разделе «Справочники и расчёты».
  Укажите источник и дату, до которой история проверена. Сохранение заменяет справочник целиком.
  Программа не поставляет актуальные ставки автоматически. Калькулятор может загрузить локальный справочник.
- Индексация в этом разделе — математическое перемножение подтверждённых индексов полных
  последовательных месяцев. Это не автоматическое юридическое определение периода и суммы взыскания.
- Связи актов: программа подсказывает возможные связи по упоминаниям номера дела и датам.
  Сотрудник проверяет стороны, суд, резолютивную часть и подтверждает связь.
- CRM: досье можно вручную связать с внутренним ID договора; сравнение проводится по документам,
  записанным в карточку договора.
- Судебная практика: локальное сохранение проверенных обзоров. Текстовый редактор скрывает
  указанные фрагменты и некоторые типовые идентификаторы; перед сохранением проверьте текст и все поля.
  Это не средство гарантированного обезличивания исходного PDF.
- Настройки → «Скачать резервную копию»: ZIP с SQLite, сохранёнными оригиналами,
  результатами обработки и инструкцией по ручному восстановлению. Не включаются временные
  загрузки и внешние сетевые папки. Архив содержит персональные данные, храните его защищённо.
- Тесты расширенных инструментов: `python tests/test_advanced.py`.
